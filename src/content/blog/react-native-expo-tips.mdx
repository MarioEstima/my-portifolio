# 5 things I learned shipping a React Native app with Expo

Shipping [rnmaps](https://github.com/MarioEstima/rnmaps) taught me a lot about
mobile development. Here are the highlights.

## 1. Expo Router changes everything

File-based routing for mobile feels as natural as it does on the web.

## 2. NativeWind = Tailwind on mobile

Being able to reuse the same mental model (and classes!) between web and mobile
massively reduced context switching.

## 3. Maps need permission choreography

Requesting location permission is easy; *gracefully* handling denial and
re-asking later is the real work.

## 4. Deep links are URLs with trust issues

Test them on cold start, warm start, and when the app was killed.

## 5. Ship with EAS

`eas build` + `eas submit` removed the entire Xcode/Android Studio ceremony from
my release process.
